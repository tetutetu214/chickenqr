# ChickenQR

中央にニワトリ画像を埋め込む QR コード生成ツール。

参考: https://bogus.jp/tools/catqr/ （ネコ版QR）

## 機能

- URL / テキスト / Wi-Fi / vCard / MeCard / mailto / tel / sms に対応
- 中央にニワトリ画像（Chicken.png）を埋め込み
- PNG / SVG 出力
- 完全クライアントサイド（入力データは外部送信されません）

## 公開URL
